Algorithm Performance Analysis: Fibonacci Timing Review

Node.js | Algorithm Analysis | Performance Testing | CSV Data Output
What it is: A Node.js performance analysis project comparing recursive and iterative Fibonacci implementations. Closure-based timers measure execution time across increasing inputs, with results exported in CSV format for analysis and visualization.
My role: Implemented both recursive and iterative algorithms, designed closure-based timing logic, executed performance tests through the terminal, and analyzed runtime behavior using generated graphs.
What I learned: This project reinforced how algorithm design directly affects scalability and efficiency. Although both implementations solve the same problem, the recursive approach becomes computationally expensive as input grows, while the iterative method remains efficient. I gained deeper insight into time complexity, performance tradeoffs, and clean function design.
