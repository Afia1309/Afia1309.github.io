Algorithm Performance Analysis: Fibonacci Timing Review

What it is: A Node.js project that compares the performance of recursive and iterative Fibonacci algorithms. Using closure-based timers, the program measures execution time for increasing sequence values and outputs results in CSV format for analysis.
My role: Implemented both recursive and iterative Fibonacci functions, designed closure-based timing logic, executed performance tests from the terminal, and analyzed the timing results using generated graphs.
What I learned: This project demonstrated how implementation choices directly impact performance. While both algorithms solve the same problem, the recursive approach scales poorly compared to the iterative version. I gained deeper insight into algorithm efficiency, time complexity, and clean function design using closures.
